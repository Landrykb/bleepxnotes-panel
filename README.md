# BleepxNotes control panel

The Telegram Mini App panel for **BleepxNotes** (@bleepxnotes_bot): registered groups, listener health, auto-join / summaries toggles, pause / resume / unregister.

Static files only — no secrets live here. All data reaches the panel through a short-lived signed snapshot handed over by the bot, and every action is verified server-side against the bot token before anything changes.
